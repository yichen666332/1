# 滤波可视化平台 - 新建与运行步骤（Qt 新手详细版）

本文档从零开始，一步一步说明如何建立项目文件夹、理解代码结构，以及如何编译和运行程序。**不使用 .ui 文件**，全部用 C++ 代码搭建界面。

## 一、项目文件夹结构（已为你创建好）

项目根目录：`D:\1111bysj\ABBQT\SensorPlatform\FilterVisualizationPlatform`

```
FilterVisualizationPlatform/
├── FilterVisualizationPlatform.pro   （qmake 工程文件，告诉 Qt 要编译哪些源文件）
├── main.cpp                          （程序入口，创建主窗口并显示）
├── mainwindow.h                      （主窗口头文件）
├── mainwindow.cpp                    （主窗口实现：左侧导航 + 右侧堆叠页面）
├── 新建与运行步骤.md                  （本说明文档）
└── modules/                          （各功能模块，每个模块一个子文件夹）
    ├── connection/                   （通讯连接）
    │   ├── connectionwidget.h
    │   └── connectionwidget.cpp
    ├── filterdata/                   （滤波数据，仅占位）
    │   ├── filterdatawidget.h
    │   └── filterdatawidget.cpp
    ├── curveanalysis/                （曲线分析，仅占位）
    │   ├── curveanalysiswidget.h
    │   └── curveanalysiswidget.cpp
    └── smarttuning/                  （智能调参 / AI辅助调参）
        ├── smarttuningwidget.h
        └── smarttuningwidget.cpp
```

**说明：**

- 每个模块一个文件夹，里面是 `xxxwidget.h` 和 `xxxwidget.cpp`，对应左侧四个按钮的四个页面。
- 串口已支持**真实串口接收**：可通过 VSPD 等虚拟串口软件实现 COM1→COM2 转发，本程序默认用 **COM2** 接收。
- 已接入三种滤波输出：**卡尔曼滤波 / 中值滤波 / H∞滤波**，接收串口数据后会实时刷新到“滤波数据”和“曲线分析”页面。

## 二、在 Qt Creator 中打开并运行（推荐）

### 步骤 1：打开工程

1. 打开 **Qt Creator**。
2. 菜单：**文件 → 打开文件或项目**。
3. 浏览到：`D:\1111bysj\ABBQT\SensorPlatform\FilterVisualizationPlatform`。
4. 选择 **FilterVisualizationPlatform.pro**，点击“打开”。
5. 若提示“配置项目”，选择你的 Qt 套件（例如 **Desktop Qt 6.x.x MinGW 64-bit**），然后“配置项目”。

### 步骤 2：编译

1. 左下角选择 **Debug** 或 **Release**。
2. 点击 **锤子图标**（构建）或按 **Ctrl+B**。
3. 等待编译完成，下方“编译输出”应显示“构建成功”或类似提示。

### 步骤 3：运行

1. 点击 **绿色三角形**（运行）或按 **Ctrl+R**。
2. 会弹出“滤波可视化平台”主窗口：
   - 左侧：蓝色圆形标志、四个按钮（通讯连接、滤波数据、曲线分析、智能调参）、底部“未连接”、接收数据/数据频率。
   - 右侧：默认显示“通讯连接”页面（串口号、波特率、连接按钮、刷新按钮）。
3. 点击左侧不同按钮，右侧会切换到对应模块（滤波数据、曲线分析、智能调参）。
4. 在“智能调参”里可以看到三个标签页（卡尔曼滤波、自适应低通滤波、Hoo滤波）、参数设置区和底部日志区。

## 三、用命令行编译和运行（可选）

若你习惯用命令行，可按下面做（需已配置好 Qt 和 MinGW 环境变量，或使用 **Qt 6.x.x for Desktop** 提供的“Qt 6.x.x (MinGW 64-bit)”命令提示符）：

### 1. 进入项目目录

```bat
cd /d D:\1111bysj\ABBQT\SensorPlatform\FilterVisualizationPlatform
```

### 2. 生成 Makefile

```bat
qmake FilterVisualizationPlatform.pro -spec win32-g++
```

### 3. 编译

```bat
mingw32-make
```

### 4. 运行

可执行文件在 **debug** 或 **release** 子目录下，例如：

```bat
debug\FilterVisualizationPlatform.exe
```

或：

```bat
release\FilterVisualizationPlatform.exe
```

根据你刚才用的是 Debug 还是 Release 构建选择对应目录。

## 四、界面与模块对应关系（按图片还原）

### 1. 主界面（对应第一张图：滤波可视化平台）

- **标题栏**：窗口标题为“滤波可视化平台”。
- **左侧面板**：

### 2. 通讯连接页面（真实串口）

- 上方圆形黑色 USB 风格图标。
- 串口号：下拉框（枚举系统真实串口；也可手动输入，例如 COM2）。
- 波特率：下拉框（9600～115200）。
- “刷新”按钮：重新枚举串口（未连接时可用）。
- “连接/断开”按钮：连接成功后会开始接收串口数据并刷新界面。

**推荐发送数据格式（每行一帧，换行结尾）：**

```text
<超声波>,<激光>\r\n
```

例如：

```text
100.23,99.87
101.10,100.40
```

### 3. 滤波数据、曲线分析

- 目前仅为占位页：标题 + 一句“此模块仅界面占位，功能待实现”，保证能正常切换、不报错。

### 4. 智能调参页面（对应第二张图：AI辅助调参）

- **标签页**：卡尔曼滤波、自适应低通滤波、Hoo滤波（每个标签页内是同一套参数布局，仅界面）。

## 五、代码不报错的原则（本项目已遵循）

1. **不用 .ui 文件**：所有界面在 `.cpp` 里用 `QWidget`、`QLayout`、`QPushButton`、`QComboBox`、`QStackedWidget` 等创建，`.pro` 里没有 `FORMS +=`，因此不会出现 .ui 相关报错。
2. **真实串口**：已使用 Qt SerialPort 打开/关闭串口，并通过换行分帧解析数据。
3. **模块分文件夹**：每个模块一个目录，头文件用 `modules/xxx/xxxwidget.h` 形式包含，与 `.pro` 中 `HEADERS`/`SOURCES` 路径一致，避免找不到文件。
4. **已接入串口与滤波**：曲线绘图为轻量自绘折线图；AI 调参页仍为界面占位（后续可把参数联动到滤波器）。

---

## 六、若出现“找不到头文件”或“无法打开源文件”

- 确认路径与 `.pro` 一致：
  - 主窗口里包含模块头文件，例如：`#include "modules/connection/connectionwidget.h"`
  - `.pro` 里：  
    `SOURCES += ... modules/connection/connectionwidget.cpp ...`  
    `HEADERS += ... modules/connection/connectionwidget.h ...`
- 若你移动了项目位置，请用 Qt Creator 重新“打开项目”指向新的 `FilterVisualizationPlatform.pro`，再重新构建。
