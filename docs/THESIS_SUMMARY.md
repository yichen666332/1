## 摘要（节选）

无人驾驶飞机的技术在军事侦察、地理测绘、农林植保等很多领域已经被广泛地运用，无人机高度测量的精准程度和稳定状况是确定无人机飞行安全以及任务执行能力的关键要素。当单一传感器处于复杂环境当中时，容易受到温度、湿度、振动以及噪声等因素的干扰，使得数据出现大幅度抖动，难以符合无人机对于高可靠性的需求。

本论文设计了一套以 Qt6 框架作为基础的多传感器融合的数据展示平台。该平台是集无人机高度数据实时采集、可视化分析以及智能调参的综合系统。平台实现了自适应卡尔曼滤波、自适应中值滤波、H∞ 滤波三种滤波算法，对原始数据和滤波后的结果进行实时对比展示，同时引入智能调整机制，增强系统在不同工况下的自适应能力。

搭建基于 Arduino 控制器实时采集超声波和激光测距传感器数据，并以数传模块上传至上位机。上位机整合三种核心滤波算法：自适应卡尔曼滤波能够高效地对高斯噪声进行平滑处理，滤波后**标准差从 8.55 cm 降低到 7.44 cm，改善 12.97%**；自适应中值滤波对脉冲噪声的**滤除率达到 100%**，最大脉冲幅度从 33.47 cm 减小到 4.28 cm，改善 87.22%；H∞ 滤波在模型失配的强干扰环境中，将**最大估计误差控制在 8.2 cm**，展现出强鲁棒性。平台引入 AI 智能调参机制，依据数据统计特征进行分析并优化，使**滤波综合评分从低于 70 分提升到 80 分左右**。对于无人机高度数据的处理，一般采用「卡尔曼滤波 + 中值滤波」组合以确保平稳输出；当环境不确定性强时，选用「卡尔曼滤波 + H∞ 滤波」组合以获得更强鲁棒性。

本平台接收并处理**每秒 50 帧以上**的多源数据，为多传感器融合算法的研究提供了一个高实时性、强可视化且具备自适应能力的完整验证环境。

## 关键结论节选（第 5 章 5.1）

本文针对无人机高度测量系统中单一传感器易受环境干扰、数据抖动严重的问题，设计并实现了一套基于 Qt6 框架的多传感器融合数据显示平台。平台集成了超声波和激光两种传感器的数据采集、串口通信传输、多种滤波算法处理、实时可视化显示以及 AI 智能调参等功能，为无人机高度测量系统的研究与开发提供了一体化解决方案。

主要工作：

1. **系统总体架构设计**：采用上下位机协同工作模式，将系统划分为物理层、数据链路层和应用层，各层职责清晰、功能解耦，确保可维护性和可扩展性。
2. **硬件平台搭建**：以 Arduino Uno R3 为下位机核心，集成 HC-SR04 超声波传感器和 TOF050 激光传感器，实现高度数据采集和初步滤波处理。
3. **可靠的串口通信协议**：包含帧头帧尾识别、CRC 校验等机制，有效解决粘包、丢包和误码问题；实测在 115200 波特率下 8 小时连续运行丢包率在 **5% 左右**。
4. **三种核心滤波算法**：完成自适应卡尔曼滤波、自适应中值滤波和 H∞ 滤波的工程实现；自适应卡尔曼使数据标准差降低 **12.97%**，自适应中值对脉冲噪声滤除率达 **99%**，H∞ 在强干扰环境下表现出优异鲁棒性。
5. **智能调参模块**：基于数据特征提取和参数推荐引擎，实现滤波参数自动优化。
6. **跨平台图形界面**：基于 Qt6 开发功能完整、操作流畅的 GUI，集成数据采集显示、实时波形绘制、滤波算法切换、参数调节、数据保存等核心功能。

## 实测与仿真数据汇总

| 类别 | 指标 | 结果 |
| --- | --- | --- |
| 吞吐 | 多源数据帧率 | ≥ 50 帧/秒 |
| 通信 | 115200 bps / 8 小时丢包率 | ≈ 5% |
| 单算法 | 卡尔曼滤波标准差 | 8.55 cm → 7.44 cm（↓12.97%） |
| 单算法 | 中值滤波脉冲滤除率 / 最大脉冲幅度 | 99%~100%；33.47 cm → 4.28 cm（↓87.22%） |
| 单算法 | H∞ 强干扰最大估计误差 | 8.2 cm |
| 组合 | 中值 → 卡尔曼 | 高斯噪声抑制率 91.5%、脉冲滤除率 89.4% |
| 组合 | 卡尔曼 ↔ H∞ 切换 | 最坏情况误差 13.6 cm → 11.8 cm |
| 智能调参 | 无 AI → 有 AI 综合评分 | < 70 → ≈ 80 |

## 后续展望（第 5 章 5.2 要点）

- 扩展更多传感器：气压计、IMU、GPS 等多源信息融合；
- 探索基于深度学习的融合算法与更智能的调参机制；
- 边缘计算部署，把滤波算法移植到机载嵌入式平台；
- 集成 Wi-Fi / 蓝牙 / LoRa 无线数传，摆脱有线串口限制；
- 支持多无人机同时监控与协同数据融合。
